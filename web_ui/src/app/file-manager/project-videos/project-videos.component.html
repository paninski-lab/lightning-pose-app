This panel shows video files in folders whose names start with videos, including files in subfolders. Each of those folders is listed here. Uncheck a folder to leave it on disk and keep it out of the app until this app restarts. A single-view name looks like session.ext. A multiview name looks like session_view.ext. File names are checked each time the list is refreshed, and a problem is shown beside that file. All-intra encoding is optimal for analysis.

  • Refresh reloads this list.
  • Check All Encodings reports whether every listed video is all-intra.
  • Process All replaces every listed video with an all-intra copy in the same folder.
  • Rename Selected changes the filename in that folder.
  • Check Selected Encoding reports whether the selected video is all-intra.
  • Process Selected replaces the selected video with an all-intra copy in the same folder.
